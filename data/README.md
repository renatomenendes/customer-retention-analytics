# Dados do case

A fonte utilizada é uma planilha **sintética e anonimizada**, conforme informação do responsável pelo case. Nenhum registro corresponde a um cliente real da operadora. A fonte original em formato XLSX permanece fora do Git; o repositório inclui código reproduzível e os agregados apresentados no estudo.

Os indicadores e relações observados caracterizam **este conjunto de dados de exercício**. Não demonstram taxas populacionais de empresas reais, comportamento de clientes reais ou eficácia causal de ofertas. A documentação deve preservar os denominadores, a temporalidade M0/M30 e as definições fornecidas pelo enunciado.

O pipeline de testes automatizados utiliza fixtures sintéticas pequenas, sem depender da planilha completa.
